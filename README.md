# Diaspora & Expat Real Estate Portal (Ethiopia)

Website focused on selling 70% finished high-value apartments in Ethiopia to diaspora and expatriate buyers.

---

## 📂 Project Directory Structure

```text
diaspora-apartments/
│
├── design-assets/                     <-- 🎯 DROP YOUR ASSETS HERE
│   ├── screenshots/                   <-- Put design screenshots & UI mockups here
│   └── prompts-and-notes/             <-- Put client brief, prompt, and notes here
│
├── public/
│   └── images/
│       ├── properties/                <-- Property photos (interior, exterior, floor plans)
│       └── branding/                  <-- Logos, banners, hero graphics
│
└── src/
    ├── components/                    <-- Reusable UI components (Hero, Cards, Calculator, etc.)
    ├── styles/                        <-- Global styles & Tailwind CSS
    └── data/                          <-- Apartment listings data, amenities, FAQs
```
